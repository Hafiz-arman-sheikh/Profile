# Hafiz Arman Sheikh — Developer Portfolio

A responsive personal portfolio built with **React 19**, **Vite 8**, **Tailwind CSS 4**, **Motion** and **Lucide React**.

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

## Production build

\`\`\`bash
npm run build
npm run preview
\`\`\`

## Tech stack

- React 19 with reusable components and React state
- Vite 8 for local development and production builds
- Tailwind CSS 4 using the official Vite plugin
- Motion for lightweight interface animations
- Lucide React for icons
- Vercel deployment configuration

## Portfolio sections

- Intro and contact links
- About and professional background
- Skills grouped by current experience and learning stage
- Filterable project showcase
- Education and career journey
- Responsive navigation and light/dark theme toggle

# ⚡ HAFIZ ARMAN SHEIKH — Modern Developer Portfolio

Welcome to the official repository of my personal portfolio website! This project showcases my technical skills, educational background, featured web developments, and contact information through a modern, responsive, and highly interactive Cyber-Grid UI.

---

## 🌟 Key Features

- **Dynamic Particle Canvas Background:** Interactive node/particle network rendering smoothly via JavaScript HTML5 Canvas.
- **Interactive 3D Card Tilts:** Custom JavaScript hover interactions for skill and project cards.
- **Glowing Follower Cursor:** Dynamic visual lighting effect following user mouse movements.
- **Fully Responsive & Clean UI:** Mobile-first layout designed using CSS Flexbox & Grid architectures.
- **Professional Emojis & Visual Styling:** Modern aesthetic touches without compromising professional standard.

---

## 🛠️ Tech Stack & Tools Used

- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Styling & Frameworks:** Modern CSS Custom Variables, Flexbox, CSS Grid, Bootstrap
- **Icons & Fonts:** FontAwesome 6, Google Fonts (*Plus Jakarta Sans* & *Space Grotesk*)
- **Deployment & Version Control:** Git, GitHub, Vercel / Netlify
